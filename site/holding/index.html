Software for Interpretative Phenomenological Analysis

Idiograph is free, open-source software for researchers who work closely with interview transcripts. You write notes and experiential statements beside each passage, then gather them into personal and group experiential themes. It runs on your own computer, Mac, Windows or Linux, and keeps your project in files there.

This is an early preview, a proof of concept to explore what software for IPA can be. It has not been fully tested or reviewed, so please don't rely on it for anything important: your data could be damaged or lost, so keep copies of your work. It is not yet a replacement for the software you use day to day. Tell me what you think with the bug button or by email. Please keep it to yourself for now: don't share it or post about it.

Idiograph is for Mac, Windows and Linux computers.

Opening it the first time on a Mac

This preview is not signed yet, so the first time you open it, macOS says it cannot check it. Click Done, then in System Settings, Privacy and Security, click Open Anyway. You only do this once.

Opening it the first time on Windows

This preview is not signed yet, so the first time you run the installer, Windows says it protected your PC. Click More info, then Run anyway. You only do this once.
